# 🌍 Carbon Footprint Calculator

## 📌 Overview

The **Carbon Footprint Calculator** is a web-based application developed using **Python and Flask** that estimates the carbon emissions generated by users based on their lifestyle and daily activities. The goal of this project is to promote environmental awareness and help users understand how their habits impact the environment.

This project demonstrates the use of **web development, backend logic, and data processing** to calculate and display carbon emission results in an easy-to-understand format.

---

## 🚀 Features

* Calculate carbon footprint based on user inputs
* Simple and user-friendly web interface
* Store and manage emission data
* Display calculated carbon emission results
* Promote awareness about sustainable living

---

## 🛠️ Technologies Used

* **Python**
* **Flask**

## ⚙️ Installation & Setup

### 1. Clone the repository

```
git clone https://github.com/your-username/carbon-footprint-calculator.git
```

### 2. Navigate to the project folder

```
cd carbon-footprint-calculator
```

### 3. Install required dependencies

```
pip install flask pandas
```

### 4. Run the application

```
python app.py
```

### 5. Open the application in browser

```
http://127.0.0.1:5000
```
